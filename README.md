# 은설, 은채만의 낱말놀이 v1.6.0

## 배포 상태
이 폴더는 GitHub + Vercel용 배포 소스입니다. 파일을 받은 것만으로 운영 사이트가 업데이트되지는 않습니다.
기존 저장소 kosuk1231/ko_twins의 운영 브랜치 main에 아래 파일·폴더를 업로드하고 Vercel의 새 배포가 Ready인지 확인하세요.

## 이번 구성
- 일반 낱말: 11개 주제 × 20장 = 220장.
- 동물 / 과일 / 채소 / 탈것 / 사물 / 의류 / 음식 / 곤충·작은 생물 / 신체 / 사람 / 자연.
- 기존 뽀로로·아기상어·타요 원본 24장 유지. 새로 그리지 않았습니다.
- 기본 사용 가능 카드 244장. 이전에 이미지를 등록한 선택 캐릭터 5종은 저장 자료가 있을 때 추가로 표시됩니다.
- 검토한 도감의 낱말, 두 낱말 문구, 이미지 파일, 셀 좌표를 그대로 사용합니다.
- 일반 그림 220장은 assets/sheets의 WebP 11개로 묶습니다. 1개 파일은 5열×4행이며, 앱에서 해당 부분만 표시합니다.
- 사진 표시와 캐릭터 분류, 부모 녹음, AI 음성 준비, 파일 및 가족 클라우드 백업을 유지합니다.
- 찾기 놀이는 정답을 선택하기 전 버튼이나 오른쪽 화살표로 넘어갈 수 없습니다.
- 권장 시간이 지나도 현재 질문을 임의로 끝내지 않습니다. 현재 질문에 답하고 다음 버튼을 누를 때 마무리합니다.
- 기기별 화면 안정화, 더블탭 확대 방지, 부모 입력창과 접근성 설정을 유지합니다.

## 업데이트 순서
1. 기존 앱 → 부모 → 저장·백업 → 백업 파일 저장. 백업 JSON은 개인 파일로 보관하고 GitHub에 올리지 마세요.
2. 이번 ZIP을 새 빈 폴더에 압축 해제하세요. 이전 버전 폴더에 덮어 풀지 마세요.
3. GitHub의 기존 저장소 첫 화면 → Add file → Upload files.
4. 압축을 푼 폴더 '안의 파일·폴더' 전체를 올립니다. ZIP 자체나 바깥 폴더를 올리지 마세요.
5. index.html, sw.js, assets, api, speech-content.json, vercel.json 등이 저장소 최상위에 놓이게 합니다.
6. 변경을 기존 운영 브랜치에 반영한 후 Vercel에서 최신 배포가 Ready인지 확인합니다.
7. 같은 운영 주소를 열어 v1.6.0 / 주제 12개 / 기본 244장을 확인합니다.
8. 예전 화면이면 https://ko-twins.vercel.app/recover.html → 수정본 적용하기 → v1.6.0 준비 완료 → 앱 열기.
9. 온라인에서 '화면 저장됨'을 확인한 후 비행기 모드에서 앱을 다시 열어 그림과 부모 녹음을 각각 확인합니다.

기존 assets/cards 등의 옛 파일을 먼저 삭제할 필요는 없습니다. 새 앱이 그 파일들을 참조하지 않으면 놀이에 영향을 주지 않습니다.
이번 ZIP의 파일은 55개입니다. GitHub 저장소의 전체 파일 개수가 아니라 이번에 동시에 업로드하는 파일 수를 확인하세요.

## 기존 데이터 보호
IndexedDB 이름 word-garden / 버전 1 / media 저장소, 설정 키와 기존 낱말 ID를 유지했습니다.
기존 낱말의 두 낱말 문구도 유지됩니다. 앱 업데이트용 캐시와 부모 녹음 저장소는 별개입니다.
Service Worker는 새 앱과 모든 필수 그림이 준비돼야 활성화됩니다. 일부 파일이 누락되면 설치를 취소하며 이전 앱 캐시를 남깁니다.
recover.html은 앱 파일만 갱신합니다. 녹음·사진·설정을 초기화하거나 삭제하지 않습니다.
웹사이트 데이터 삭제, 홈 화면 앱 재설치, 다른 운영 주소로 변경하는 방법을 업데이트에 사용하지 마세요.
부모 녹음·가족 사진·백업 JSON은 ZIP이나 GitHub에 포함하지 마세요.

## Vercel 설정
기존 프로젝트를 그대로 사용합니다. 이번 확장에는 새 환경변수가 필요하지 않습니다.
Framework: Other / Root: 저장소 최상위 / Build Command: 비움 / Output Directory: .
package.json의 의존성 설치는 Vercel 기본 설정을 유지하세요. 프로젝트별로 Install Command를 억지로 비워 의존성 설치를 막지 마세요.
vercel.json은 기존 서버 API 파일과 필요한 JSON 자료를 포함합니다.
AI 음성을 새로 만들 때만 OPENAI_API_KEY 및 WORD_GARDEN_PARENT_TOKEN이 필요합니다.
가족 클라우드 백업을 사용하려면 기존 Vercel Private Blob 연결과 WORD_GARDEN_PARENT_TOKEN을 유지하세요.
그림과 기본 놀이 사용에는 AI 생성 API 키가 필요하지 않습니다.
AI 음성이 미리 생성된 배포본은 아닙니다. 신규 낱말은 부모 녹음/기기 음성을 사용하거나 부모 화면에서 합성음성을 준비합니다.
외부 서비스 사용 비용과 실제 제공 범위는 해당 계정 설정에서 확인하세요.
