# 말랑말랑 낱말정원 1.0.0

고은설·고은채와 부모가 함께 사용하는 한국어 낱말 카드놀이 웹앱의 1차 작동 버전입니다.
웹앱 소스이며, 이 ZIP 자체가 App Store 설치 파일이나 이미 배포된 설치 주소는 아닙니다.

## 가장 먼저 할 일

컴퓨터에서 화면과 조작 확인: `index.html`을 Chrome 또는 Safari로 엽니다.
실제 iPhone/iPad 설치: 이 폴더의 웹 파일을 HTTPS 정적 웹호스팅에 배포한 다음 Safari에서 열고 홈 화면에 추가합니다.
앱을 새 홈 화면 아이콘으로 온라인에서 한 번 실행한 뒤 ‘화면 저장됨’을 확인합니다.
음성은 별도로 부모 설정 → 오프라인에서 확인하고, 비행기 모드로 앱을 완전히 닫았다 다시 열어 시험하세요.
파일 앱의 HTML 미리보기는 설치된 앱과 다릅니다.

## 현재 들어 있는 기능

- 은설 / 은채 / 함께 선택 및 “은설아”, “은채야” 이름 부르기.
- 낱말 보기, 듣고 찾기, 두 낱말 말하기, 같은 그림 찾기.
- 동물 12, 과일 8, 자동차 8, 음식 10, 사람 8 = 기본 놀이 카드 46장.
- 뽀로로·크롱·루피·에디·포비·패티·해리·로디 이름 템플릿 8개. 원본 캐릭터 이미지는 포함하지 않았습니다. 부모가 사용할 수 있는 사진/그림을 넣은 카드만 놀이에 나타납니다.
- 기본 그림은 기기 이모지입니다. 실제 고양이 사진 1장 포함. 부모 메뉴에서 사과·바나나 사진 2장 추가 받기 가능(그때만 네트워크 필요). 모든 카드의 사진을 직접 교체할 수 있습니다.
- 한국어 로컬 음성만 선택합니다. 원격/클라우드 음성은 사용하지 않습니다.
- 부모 목소리 녹음: 아이 이름, 낱말, 두 낱말 문장, 아이별 찾기 질문. 녹음은 최대 8초, 이 브라우저에 저장.
- 기본 카드 6장, 3분 마무리 안내. 카드 수 4/6/8, 시간 1/3/5분, 선택지 2/3장 조정.
- 부모 버튼 1.2초 길게 누르기. 감점·순위·광고·연속출석·자동 카드 넘김 없음.
- 기기 내 설정/미디어 저장, 부모용 낱말 기록, JSON 백업/복원.
- 아이폰과 아이패드 간 자동 동기화 없음. 백업 파일로 사진·녹음·설정을 옮길 수 있습니다. 놀이 기록은 현재 백업에 포함되지 않습니다.

## 오프라인과 지연에 대한 정확한 범위

앱 화면과 기본 카드: HTTPS 배포 후 Service Worker가 설치되면 캐시에 저장하도록 구현했습니다.
사진/녹음: 사용자가 저장한 자료는 IndexedDB에 보관합니다. 별도 서버에 업로드하지 않습니다.
음성: 설치된 한국어 로컬 음성이 브라우저에 제공되어야 모든 문장을 읽을 수 있습니다. iOS 음성 메뉴에서 내려받은 음성이 언제나 Safari에 나타난다고 보장하지 않으므로 실기기 확인이 필요합니다.
녹음한 항목은 녹음을 우선 재생합니다. 일부 낱말만 녹음했을 때 다른 질문/안내문까지 녹음으로 대체되지는 않습니다.
완전한 0ms 지연은 보장하지 않습니다. 카드 전환은 네트워크 대기 없이 수행하고, 현재 놀이에 필요한 녹음을 Web Audio 버퍼로 미리 준비합니다.
기기 음성 초기화, 기기 성능, 블루투스 출력, 운영체제 상태에 따른 지연은 실제 장치에서 점검해야 합니다.
브라우저 데이터 삭제, 저장 공간 부족, 장기간 미사용 등에 의해 로컬 데이터가 지워질 수 있습니다. 백업을 보관하세요.
‘화면 저장됨’은 음성까지 확인했다는 뜻이 아닙니다.

## HTTPS 배포: Cloudflare Pages 예시

Cloudflare Pages의 Direct Upload에서 ZIP 또는 압축을 푼 폴더를 업로드할 수 있습니다.
배포할 파일의 최상위에 index.html, sw.js, manifest.webmanifest, 아이콘 PNG 3개가 있어야 합니다.
빌드 명령/npm 설치/서버/API 키는 필요 없습니다.
개발 소스와 README도 올릴 수 있지만, 자신의 백업 JSON이나 가족 사진·녹음 파일은 공개 호스팅에 별도로 올리지 마세요.
이 기본 소스에는 은설·은채 이름이 포함됩니다. 공개 배포하면 기본 이름이 노출될 수 있으므로 필요하면 배포 전에 바꾸거나 접근 제한을 적용하세요.
비공개 접근 제한 서비스 사용 시에도 Service Worker 파일과 기본 자산이 동일 출처에서 정상적으로 내려받아지는지 확인해야 합니다.

참고: https://developers.cloudflare.com/pages/get-started/direct-upload/

## 컴퓨터 개발용 서버

Python 3가 있을 경우 이 폴더에서:
```
python start.py
```
Mac에서는:
```
python3 start.py
```
localhost 미리보기용이며 같은 Wi-Fi의 iPhone에서 HTTP 주소로 접속하는 방식은 오프라인 설치 테스트를 대신하지 않습니다.
Python이 없어도 단일 HTML의 화면과 기본 놀이를 컴퓨터 브라우저에서 확인할 수 있습니다. 파일 모드의 저장·녹음 지원은 브라우저에 따라 다릅니다.

## 선택 도구: Mac에서 전체 오프라인 음성팩 만들기

기기 음성에 덜 의존하고 이름·낱말·질문 전체를 미리 만든 오디오로 사용하려는 경우를 위한 도구입니다.
**음성팩 자체는 이 ZIP에 포함되어 있지 않으며, 생성 도구만 포함되어 있습니다.**
Mac에 한국어 음성이 설치되어 있어야 하며, 외부 TTS 서버가 아닌 macOS 기본 `say`와 `afconvert`를 사용합니다.
이 생성 도구의 실제 macOS 실행은 제작 환경에서 검증하지 못했습니다.

```
python3 make_voice_pack.py
```

생성된 word-garden-voice-pack.json을 아이폰/아이패드에 옮겨 부모 설정 → 오프라인 → 백업 불러오기를 선택합니다.
권장 설정도 함께 불러옵니다. 기존 사진은 유지하고, 같은 이름의 녹음 항목은 음성팩으로 교체합니다.
이름·낱말·두 낱말·아이별 찾기 질문·다시 보기 안내를 합쳐 276개 오디오를 생성합니다.
기존 파일을 수정한 경우 원본 음성 대신 부모 녹음을 다시 할 수 있습니다.

## 수정 및 다시 빌드

app.js: 화면/놀이/녹음/저장 기능
styles.css: 반응형 스타일
content.json: 카드 내용 및 기본 사진
template.html: HTML 골격

소스를 바꾸면:
```
python3 build.py
```
index.html을 다시 만듭니다.
배포 업데이트 때에는 app.js의 SW_VERSION과 sw.js의 CACHE 버전을 함께 올리고, index.html을 다시 빌드해 배포하세요.
기존 미디어 데이터베이스 이름을 바꾸지 않으면 사진과 녹음을 유지할 수 있습니다. 데이터 마이그레이션 변경 시 별도 검토가 필요합니다.

## 검증 범위

Chromium에서 격리된 HTML 렌더링/클릭 테스트, 이름 선택, 네 가지 놀이, 부모 잠금, 시간 마무리, 사진 리사이즈, 백업 입력 검증, 390/820/1180픽셀 레이아웃을 확인했습니다.
사진 저장 테스트는 모의 저장소를 사용했습니다.
Service Worker 캐시 로직은 파일 기반 모의 CacheStorage로 검사했습니다.
테스트 환경의 네트워크/마이크 제한 때문에 실제 브라우저의 HTTPS 설치·종료 후 오프라인 재실행·IndexedDB 영구 저장·실제 마이크 녹음·사진팩 다운로드는 검증하지 못했습니다.
실제 iPhone/iPad, Apple 한국어 음성 품질/오프라인 가용성, 하드웨어 지연, macOS 음성팩 생성은 아직 검증하지 않았습니다.
검증 결과는 TESTING.md와 tests/에 포함됩니다.

낱말·관찰·간단한 선택·부모와의 대화를 위한 놀이 도구입니다.
두뇌 활성화, 지능 향상, 언어 발달 효과를 보장하거나 발달 수준을 진단하지 않습니다.
3분은 앱의 추천 기본값이며 의학적으로 정해진 사용 시간은 아닙니다.
