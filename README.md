# 은설, 은채만의 낱말놀이 v1.5.0

GitHub 웹 업로드와 Vercel 배포용 패키지입니다. 캐릭터 원본 24장과 기존 카드/녹음 기능을 유지하면서 아래 기능을 추가했습니다.

- 앱 이름: **은설, 은채만의 낱말놀이**
- 듣고 찾기 / 같은 그림 찾기에서는 **정답 카드를 선택하기 전까지 다음 카드 버튼이 비활성화**됩니다.
- 기존 기기 파일 백업에 더해 **Vercel Private Blob 가족 클라우드 백업**을 사용할 수 있습니다.
- 클라우드 백업은 사진, 부모 녹음, 준비한 AI 음성, 설정을 백업 JSON 하나로 저장하며, 여러 iPhone/iPad에서 같은 부모 암호로 가장 최근 백업을 복원할 수 있습니다.
- 기존 IndexedDB 이름과 media key를 바꾸지 않아 같은 운영 주소로 업데이트하면 기존 로컬 녹음을 유지합니다.

## GitHub 업로드

ZIP을 새 폴더에 풀고 **폴더 안의 파일과 폴더 전체**를 기존 저장소 루트에 업로드합니다. `index.html`만 올리면 안 됩니다.

필수 루트 파일에는 `index.html`, `sw.js`, `manifest.webmanifest`, `package.json`, `vercel.json`, `assets/`, `api/`가 있습니다.

## Vercel Private Blob 연결 - 클라우드 백업을 쓸 때만 필요

1. Vercel의 `ko-twins` 프로젝트를 엽니다.
2. **Storage**에서 새 **Blob** 저장소를 만들고 접근 유형은 **Private**로 선택합니다.
3. 그 Blob 저장소를 현재 프로젝트에 연결합니다. 2026년 신규 연결은 OIDC 인증이 기본이며, 기존 방식의 Blob 토큰 연결도 SDK에서 지원됩니다.
4. 프로젝트 `Settings -> Environment Variables`에 `WORD_GARDEN_PARENT_TOKEN`을 32자 이상의 임의 문자열로 설정합니다.
   - 이미 AI 음성 생성 때문에 이 값을 설정했다면 같은 값을 그대로 사용합니다.
   - `OPENAI_API_KEY`는 AI 음성 생성에만 필요하며 클라우드 백업에는 필요하지 않습니다.
5. **Redeploy**합니다.
6. 앱 -> 부모 -> 저장·백업 -> 가족 클라우드 백업에서 같은 `WORD_GARDEN_PARENT_TOKEN` 값을 입력합니다.
7. 첫 기기에서 `클라우드에 백업`, 다른 기기에서 `클라우드에서 불러오기`를 사용합니다.

클라우드 파일은 Private Blob에 저장됩니다. 앱 서버는 10분짜리 단일 파일용 서명 URL만 발급하고, 브라우저가 Blob 저장소와 직접 업로드/다운로드합니다. 서버의 Blob 자격 증명은 브라우저로 보내지 않습니다.

## 데이터 보존 주의

- 업데이트 전에 `부모 -> 저장·백업 -> 백업 파일 저장`으로 로컬 백업도 하나 보관하는 것을 권장합니다.
- 기존 운영 주소를 계속 사용하고 Safari 사이트 데이터나 홈 화면 앱을 업데이트 목적으로 삭제하지 마세요.
- 클라우드에서 불러오기는 같은 media key를 교체하고 다른 로컬 항목은 유지합니다.
- 클라우드 백업은 명시적으로 버튼을 눌렀을 때 실행됩니다. 녹음 직후 자동 전송하지 않습니다.
- 각 기기의 로컬 녹음은 기존처럼 IndexedDB에 우선 저장되고 저장 후 다시 읽어 검증합니다.

## Vercel 설정

기존과 동일하게 Framework Preset은 `Other`를 사용할 수 있습니다. `vercel.json`에 build/output 설정이 포함되어 있습니다. `package.json`에는 `@vercel/blob` 의존성이 추가되어 Vercel Functions의 클라우드 백업 API에서 사용됩니다.

## v1.5.0 화면 안정화 · UI/UX
- iPhone/iPad의 현재 논리 뷰포트를 세로/가로 방향별로 고정해 Safari 주소창·키보드 변화로 놀이 화면이 갑자기 재배치되는 현상을 줄였습니다.
- `touch-action: manipulation`과 동일 대상 연속 탭 방어로 아이의 더블탭 확대를 막습니다. 의도적인 두 손가락 확대는 접근성을 위해 유지합니다.
- Safe Area(inset), 최소 44pt 터치 영역, 모바일 입력 16px 이상, focus-visible, reduced-motion을 유지합니다.
- 화면 분류: 휴대폰(짧은 변 <=600), 태블릿(<=1024), 큰 화면. 방향 전환 시에만 새 크기로 다시 고정합니다.
