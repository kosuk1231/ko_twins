# Asset record - v1.7.0

The 220 assets/vector/*.svg files are vector-only miniature illustrations with gradient shading.
50 came from the earlier project vector artwork; 170 were authored for this replacement set.
No external icon library was incorporated. No raster thumbnail is embedded in those SVGs.
The 1024x1024 intrinsic display dimensions and 400-unit viewBox are not a raster resolution limit.
Rendering is vector-based at the browser's display scale.

assets/characters/*.webp (24 files) are the unchanged crops of images supplied by the parent earlier in this conversation.
This release does not increase the resolution of those character originals or claim ownership of the characters.
Existing character source metadata is retained in character-sources.json and bundled-characters.json.

The standalone review HTML is for inspection only, not the app's index.html.
