1. 먼저 백업

기존 앱의 부모 → 오프라인 → 백업 파일 저장. 새 버전에서는 ‘저장·백업’ 탭입니다.

업데이트를 위해 웹사이트 데이터를 삭제하거나 앱을 제거하지 마세요.
같은 운영 주소를 사용하세요. 아이폰·아이패드의 저장소는 별개입니다.

2. GitHub에 파일 교체

ZIP을 풀고 파일과 폴더를 모두 저장소 최상위에 올리세요. ZIP 자체 또는 index.html만 올리지 마세요. assets와 api 폴더도 포함합니다.

Vercel: Other / Root Directory 최상위 / Build Command 비움 / Output Directory .. 제공된 vercel.json이 기본 설정을 포함합니다.

배포가 완료되면 온라인으로 앱을 열고, 새 버전이 준비된 후 완전히 닫았다 다시 열어 v1.2.0을 확인합니다.

3. 부모 목소리 저장

부모 버튼 1.2초 길게 누르기 → 부모 녹음 → 주제·항목 선택 → 녹음 시작 → 말하기 → 멈추고 저장.

‘저장·재확인 완료’가 뜬 뒤 ‘저장한 소리’를 직접 눌러 확인하세요. 이름 인사, 낱말, 문장, 아이별 질문은 각각 따로 녹음합니다.

저장 오류가 나면 앱을 닫기 전에 ‘다시 저장’ 또는 ‘녹음 파일 보관’을 누르세요. 임시 녹음은 앱이 종료되면 사라질 수 있습니다.

4. 기기 음성과 AI 6종

기기 음성은 별도 API 설정 없이 사용합니다. 표시되는 한국어 목소리 수는 기기에 따라 다릅니다. 5가지 읽기 스타일은 속도·높낮이를 바꾸는 설정입니다.

AI 목소리 파일은 미리 포함되어 있지 않습니다.

Coral · Nova · Shimmer · Alloy · Onyx · Sage를 실제로 생성하려면 Vercel 환경변수 두 개를 설정한 뒤 Redeploy해야 합니다.

이름넣을 값
OPENAI_API_KEY본인 OpenAI 프로젝트 API 키
WORD_GARDEN_PARENT_TOKEN32자 이상의 임의 비밀 문자열

API 키는 GitHub나 앱 화면에 넣지 마세요. 앱에는 위 TOKEN 값인 부모 생성 암호만 입력합니다.

앱 → 부모 → 음성 선택 → AI 음성 선택 → ‘AI 음성 만들기 설정’ 펼치기 → 생성 암호 입력 → 샘플 1개 먼저 생성 → 발음 확인 → 원하는 주제 준비.

생성 시 API 사용료가 발생합니다. 이름 등이 포함된 생성용 텍스트가 OpenAI로 전송됩니다. 부모 목소리나 사진은 보내지 않습니다. 저장된 부모 녹음은 AI로 덮어쓰지 않습니다.

목소리는 영어에 최적화되어 있어 한국어 발음 차이가 있을 수 있습니다. 실제 샘플을 듣고 고르세요.

5. 마지막으로 오프라인 확인

부모 → 저장·백업에서 그림과 음성 상태 확인 → 비행기 모드 → 앱을 닫았다 다시 열기 → 그림·부모 녹음·선택한 합성음성을 각각 시험하세요.

화면 저장은 모든 음성이 준비됐다는 뜻이 아닙니다. 저장되지 않은 AI 항목은 기기 음성으로 읽습니다. 자동 기기 간 동기화는 없으므로 백업 파일로 옮기세요.

검증 범위

브라우저 UI, 녹음 인코딩, 저장 실패 처리, 캐시 및 API 보안 로직을 시험했습니다. 저장소·기기 음성·서버 응답은 모의 환경을 포함합니다. 실제 아이폰·아이패드의 마이크, 데이터 보존, PWA 오프라인 재실행, 라이브 AI 발음은 기기에서 확인해야 합니다.

개별 파일 구조와 보안 설정은 ZIP의 README.md, 검사 범위는 TESTING.md를 참고하세요.
