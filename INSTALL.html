‘원본 받기’를 누르거나 캐릭터 이미지를 생성할 필요가 없습니다. 첫 설치·업데이트 후 온라인에서 앱을 열어 저장을 완료하세요.

1. 백업하고 파일 전체를 교체하세요

기존 앱 → 부모 → 저장·백업 → 백업 파일 저장.

ZIP을 풀고 안의 파일·폴더 전체를 기존 GitHub 저장소에 교체하세요. assets/characters에 원본 24장이 있습니다. index.html만 교체하지 마세요.

기존 Vercel 프로젝트와 같은 운영 주소를 사용하세요. 다른 프로젝트로 새로 만들지 않아도 됩니다. 기존 vercel.json 설정을 포함했습니다.

앱이나 Safari 웹사이트 데이터를 삭제하지 마세요.

이번 수정은 기존 녹음·사진 데이터를 삭제하지 않습니다. 그래도 별도 백업은 먼저 받아두세요.

2. 새 버전과 그림을 확인하세요

배포 후 온라인에서 앱을 열어 v1.3.1을 확인하세요. 이전 버전이면 부모 → 저장·백업 → 새 버전 확인 후, 녹음을 마친 상태에서 앱을 완전히 닫았다가 다시 엽니다.

캐릭터 → 뽀로로 / 아기상어 / 타요 → 함께 놀이 시작으로 바로 사용할 수 있습니다.

캐릭터에 직접 등록한 그림이 있으면 그것이 먼저 나옵니다. 포함된 원본으로 돌아가려면 부모 → 캐릭터 → 해당 카드에서 ‘내 사진 지우기’를 선택하세요. 이 버튼은 해당 카드 사진만 지우며 목소리는 지우지 않습니다.

3. 오프라인은 그림과 소리를 따로 확인하세요

첫 설치·업데이트 후 ‘화면 저장됨’을 확인하세요. 비행기 모드 → 앱 종료 → 재실행하여 원본 그림과 부모 녹음이 각각 나오는지 확인합니다.

아이폰·아이패드는 각각 한 번 저장해야 합니다. 부모 녹음·추가 사진은 백업 파일로 옮깁니다. AI 음성 파일이 새로 생성된 버전은 아니며 기존 설정을 유지합니다.

4. 원본의 크기와 범위를 알려드립니다

AI 재생성 없이 잘라서 같은 정사각형으로 맞췄습니다. 뽀로로는 왼쪽 원형 이미지가 더 커서 그쪽을 사용했습니다. 삐삐와 뽀뽀는 함께 나온 카드 한 장입니다.

하나의 발끝 일부는 캡처에서 잘렸습니다. 없는 부분을 임의로 그리지 않았습니다. 작은 원본은 확대하면 흐릴 수 있습니다.

이전 아기상어 친구 5장의 데이터는 유지했습니다. 이번 캡처에 없는 그림은 추가하지 않았고, 기존 저장 그림이나 직접 등록한 그림이 있을 때만 놀이에 나옵니다.

검증 범위

브라우저 조작, 24장 이미지 표시, 새 타요 필터, 녹음과 백업 연결, 캐시 로직을 시험했습니다. 저장소·음성·캐시는 모의 시험을 포함합니다. 실제 Vercel, 아이폰·아이패드의 마이크와 설치 후 오프라인 재실행은 아직 확인하지 못했습니다.
