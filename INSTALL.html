은설, 은채만의 낱말놀이
v1.6.2

카드 칸 넘침 수정 + 트럭 고해상도 원본

트럭은 1448×1086px 새 원본으로 교체했습니다. 작은 그림을 확대한 파일이 아닙니다.

일반 220장 전체를 고해상도로 교체한 버전은 아닙니다.

나머지 219장은 기존 원본입니다. 기존 캐릭터 24장과 부모 녹음은 유지합니다.

1. 개인 백업

부모 → 저장·백업 → 백업 파일 저장. 개인 백업 JSON은 GitHub에 올리지 마세요.

2. 기존 저장소에 수정 파일 올리기

ZIP을 새 빈 폴더에 풀고, 안의 파일과 폴더를 저장소 첫 화면에 올려주세요. assets/hd/truck.webp가 반드시 포함되어야 합니다. 기존 assets와 api 폴더를 삭제하지 마세요.

수정본 9개 또는 전체본 56개 중 하나만 올리면 됩니다.

3. 버전 확인

Vercel 새 배포가 Ready이면 같은 운영 주소에서 v1.6.2를 확인하세요.

https://ko-twins.vercel.app/recover.html
수정본 적용하기 → 앱 열기

Safari 데이터나 홈 화면 앱을 삭제하지 마세요.

4. 동작 확인

탈것 → 같은 그림 찾기. 위쪽 기준 그림이 테두리 안에 들어가는지 확인하세요. 트럭에 개인 사진을 등록하고 사진 우선으로 설정했다면, 기본 그림 표시로 바꾸어 새 원본을 확인하세요. 개인 사진은 삭제할 필요가 없습니다.

온라인에서 화면 저장 완료 후 비행기 모드에서 그림과 녹음을 각각 확인해주세요.
