아이 화면 안정화 업데이트

더블탭 확대 방지, 기기별 논리 뷰포트 고정, Safe Area, 44pt 이상 터치 영역, iOS 입력창 자동 확대 방지를 반영했습니다.

무엇이 달라졌나요?

같은 화면을 빠르게 두 번 눌러도 임의 확대되지 않습니다. iPhone/iPad의 현재 세로·가로 방향에서 놀이 화면 크기를 한 번 고정하고, Safari UI나 키보드가 잠깐 나타나는 변화에는 화면 전체가 따라 줄어들지 않도록 했습니다. 방향을 돌리거나 화면 폭이 크게 바뀌면 새 크기로 다시 맞춥니다.

접근성을 위해 두 손가락으로 의도적으로 확대하는 동작은 막지 않았습니다.

업데이트

기존 앱에서 부모 → 저장·백업 → 백업 파일 저장을 먼저 실행하세요. ZIP을 풀어 GitHub 저장소 최상위에 파일과 폴더를 교체한 뒤 Vercel 자동 배포를 확인합니다. 같은 ko-twins.vercel.app 주소를 사용하세요.

Safari 데이터나 홈 화면 앱을 삭제하지 마세요.

기존 부모 녹음과 사진을 유지하기 위한 저장소를 그대로 사용합니다.

확인 방법

배포 후 앱의 부모 → 놀이 설정 → 화면 안정화에서 현재 기기와 논리 해상도(예: iPhone/휴대폰 · 390×844 · 세로)를 확인할 수 있습니다. 아이 화면에서 같은 카드를 빠르게 두 번 눌러도 화면 자체가 확대되지 않는지 확인하세요.
