은설, 은채만의 낱말놀이
v1.7.1 전체 그림 교체본

일반 카드 220장 전체를 개별 SVG 벡터 원본으로 교체했습니다.

기존 작은 그림을 크게 늘린 파일이 아닙니다. 부드러운 입체 음영을 넣은 벡터 일러스트로 교체한 버전입니다. 기존 3D 그림과 화풍은 다르며, 같은 디자인의 고해상도 복원본은 아닙니다.

1. 기존 녹음을 백업하세요

기존 앱: 부모 → 저장·백업 → 백업 파일 저장. 백업 JSON은 개인 파일로 보관하고 GitHub에는 올리지 마세요.

2. 세 묶음을 순서대로 올리세요

순서파일 수구성
192동물·과일·채소·탈것 80장 + 기존 캐릭터 12장
292사물·의류·음식·곤충 80장 + 기존 캐릭터 12장
381신체·사람·자연 60장 + 앱 코드·안내 21개

각 ZIP을 별도 빈 폴더에 풀고, 폴더 안의 파일과 assets/api 폴더를 기존 GitHub 저장소 최상위에 올리세요. ZIP 자체나 바깥 폴더를 올리는 것이 아닙니다. 매번 Commit changes를 누릅니다.

1번과 2번은 그림만 추가합니다. 앱을 새 그림으로 전환하는 코드는 3번에 있으므로 3번을 맨 마지막에 올리세요. 이전에 올린 그림 파일을 먼저 지우지 않아도 됩니다.

3. 마지막 배포를 확인하세요

Vercel의 마지막 배포가 Ready가 되면 기존 운영 주소에서 v1.7.1을 확인하세요. 이전 화면이 나오면 아래 복구 주소에서 수정본 적용하기 → 앱 열기를 누르세요.

https://ko-twins.vercel.app/recover.html

Safari 데이터나 홈 화면 앱을 삭제하지 마세요.

기존 녹음·사진 저장소와 낱말 식별자를 유지했습니다. 캐릭터 원본 24장과 클라우드/음성 API 파일은 변경하지 않았습니다. 새 API 키나 환경변수는 필요하지 않습니다.

4. 내가 올린 사진이 계속 보인다면

부모 → 놀이 설정 → 카드 그림에서 기본 그림을 선택하세요. 개인 사진을 우선 표시하는 설정에서는 기존 사진이 나올 수 있습니다. 사진를 삭제할 필요는 없습니다.

확인한 범위

220개 원본의 파일 존재, 배포 경로, SVG 형식, 이미지 로딩을 확인했습니다. 7가지 화면 크기에서 네 가지 놀이와 2/3개 선택지를 검사했습니다. 정답 선택 전 다음 카드 차단도 확인했습니다.

브라우저 검사는 원본 바이트를 삽입한 격리된 Chromium 환경에서 수행했습니다. 실제 아이폰/아이패드, Vercel 배포, 서비스 워커 오프라인 재실행, 마이크·클라우드 연결은 실기기에서 확인해주세요. 운영 사이트에 직접 배포하지는 않았습니다.
