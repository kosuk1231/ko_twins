설치와 첫 사용

먼저 컴퓨터에서 확인하세요.

같은 폴더의 index.html을 Chrome 또는 Safari로 열면 기본 화면과 놀이를 살펴볼 수 있습니다. 사진 저장·마이크·완전한 오프라인 설치는 아래 HTTPS 배포가 필요합니다.

1. 아이폰 설치 주소 만들기

앱 파일은 만들었지만, 공개 사이트에 배포하지는 않았습니다. ZIP을 HTTPS 정적 웹호스팅에 올리면 설치 주소가 생깁니다.

Cloudflare Pages의 Direct Upload는 ZIP 또는 폴더 업로드를 지원합니다. 업로드 최상위에 index.html이 있어야 합니다. npm이나 빌드 설정은 필요하지 않습니다.

배포 소스에는 아이 이름이 들어 있습니다. 공개 주소로 올릴 때 이름 노출을 고려해 주세요. 개인 백업 JSON·가족 사진·녹음을 호스팅에 따로 올리지 마세요.

2. Safari에서 홈 화면에 추가

아이폰·아이패드 Safari로 배포 주소 열기 → 공유 → 홈 화면에 추가 → ‘웹 앱으로 열기’가 있으면 켜기 → 추가.

새 홈 화면 아이콘으로 앱을 온라인에서 한 번 열고 ‘화면 저장됨’을 확인하세요. 아이폰과 아이패드 각각 설치해야 합니다.

3. 소리까지 따로 확인

부모 버튼을 1.2초 길게 누르기 → 오프라인 → 지금 소리 확인. 기본은 기기 안의 한국어 음성입니다.

한국어 음성이 없으면 iOS 설정 → 손쉬운 사용의 음성/읽기 메뉴에서 한국어 음성을 설치하세요. 메뉴 이름과 Safari에 제공되는 음성은 버전에 따라 달라질 수 있습니다. 설치 후 앱을 완전히 닫았다 다시 열어 확인하세요.

가장 중요한 마지막 확인

비행기 모드 켜기 → 앱 완전히 닫기 → 홈 화면 아이콘으로 다시 실행 → 카드와 소리 모두 확인. ‘화면 저장됨’이 음성까지 확인했다는 뜻은 아닙니다. 실제 아이폰·아이패드 검증은 아직 하지 못했습니다.

4. 첫 놀이는 이렇게

은설 / 은채 / 함께 고르기 → 동물 → 낱말 보기 → 함께 놀이 시작. 아이가 큰 그림을 누르면 낱말을 읽습니다. 부모는 아래 대화 문구를 참고해 한 마디만 덧붙여 주세요.

기본 카드 6장·3분 뒤에는 화면 밖 놀이를 안내합니다. 두 낱말 말하기, 두 장 중 찾기, 같은 그림 찾기도 있습니다. 점수와 경쟁은 없습니다.

5. 가족·캐릭터 사진 넣기

부모 → 카드 꾸미기 → 주제·카드 선택 → 사진 선택. 뽀로로 등은 이름 템플릿만 준비되어 있습니다. 실제 이미지를 넣은 카드만 놀이에 나타납니다.

기본 그림은 기기 이모지, 기본 사진은 고양이 1장입니다. 부모 메뉴에서 사과·바나나 사진 2장을 추가로 받을 수 있습니다. 받은 뒤에는 로컬 저장합니다.

6. 목소리와 백업

부모 목소리 녹음은 선택 기능입니다. 이름·낱말·짧은 문장·찾기 질문을 최대 8초씩 녹음할 수 있습니다. 녹음하지 않은 문장은 기기 음성이 필요합니다.

사진·녹음·설정은 이 브라우저에만 저장됩니다. 부모 → 오프라인 → 백업 파일 저장으로 보관하고, 다른 기기에서 백업 불러오기를 선택하세요. 자동 동기화는 없습니다.

Mac 사용자는 make_voice_pack.py로 전체 오프라인 음성팩을 만들 수도 있습니다. 선택 도구이며 실제 Mac에서의 실행은 미검증입니다. 자세한 설명은 README.md에 있습니다.

기억해 주세요

완전한 0ms 지연은 보장하지 않습니다. 현재 버전은 네트워크를 기다리지 않는 카드 전환과 로컬 음성 재생 방식입니다. 첫 음성 초기화·블루투스·기기 상태에 따른 지연은 실기기에서 확인해야 합니다.

데이터 삭제나 저장 공간 정리로 로컬 자료가 사라질 수 있으므로 백업을 보관하세요. 지능 향상이나 발달 효과를 보장하는 앱은 아닙니다.
